# Pong

Relive the arcade classic Pong!

### Download Instructions
``` git clone https://github.com/eldin79/pong.git ```

### Install instructions
Navigate to the pong directory.

Install uv:
``` pip install uv```

Create a virtual environment:
```uv env```

Activate the virtual environment:
- Linux: ``` source .venv/bin/activate ```
- Windows: ``` .venv\Scripts\activate ```

Install pygame:
``` pip install pygame ```

### Running instructions
Type the following in the pong directory:
``` uv run main.py ```

### Controls 
Player one:
- W - move up
- S - move down

Player two:
- Up Arrow - move up
- Down Arrow - move down
